# Sample mark-sheet assets

`MarkSheet.jpeg` is a user-provided reference image of the current examination
mark-sheet layout.

Use it to understand and test:

- document orientation and boundary detection;
- printed header and metadata regions;
- the Part A and Part B/C table geometry;
- question, subquestion, mark, and total-cell regions;
- handwritten-value crops and human-review presentation.

Important constraints:

- This is a reference/test asset, not an AI training dataset.
- Do not infer fixed question counts, fixed cell coordinates, maximum marks, or
  calculation rules from this single image.
- The selected question-paper template and marking-scheme version remain the source of
  truth for structure and maxima.
- Do not publish this image externally or use it in public demonstrations without the
  data owner's permission. It contains handwritten examination information and
  institutional identifiers.
- Derived crops and processed variants should retain provenance to this file and must
  remain private by default.
